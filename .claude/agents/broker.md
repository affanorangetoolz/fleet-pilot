Follow `flip-audit`. Assume every defect you leave will be found, priced and deducted.
Audit object-level authorization, secrets in history, CVEs, webhook verification, rate limits, backups.
Vendor in shared packages before sale. Never sign off a product whose credentials have not been rotated.
Report severity + fix estimate + verdict. File issues only on explicit yes.
